# Źródła

Dokumentacje i materiały wykorzystane przy projektowaniu i implementacji systemu.

## Backend

1. Spring Boot - dokumentacja referencyjna: https://docs.spring.io/spring-boot/reference/
2. Spring Security - dokumentacja referencyjna: https://docs.spring.io/spring-security/reference/
3. Spring Security - `BCryptPasswordEncoder` (hashowanie haseł):
   https://docs.spring.io/spring-security/site/docs/current/api/org/springframework/security/crypto/bcrypt/BCryptPasswordEncoder.html
4. Hibernate ORM - dokumentacja: https://hibernate.org/orm/documentation/
5. Jakarta Persistence (JPA) - specyfikacja: https://jakarta.ee/specifications/persistence/
6. JSON Web Token (JWT) - RFC 7519: https://datatracker.ietf.org/doc/html/rfc7519
7. Biblioteka JJWT (implementacja JWT dla Javy): https://github.com/jwtk/jjwt
8. Apache Maven - dokumentacja: https://maven.apache.org/guides/
9. HikariCP (pula połączeń JDBC): https://github.com/brettwooldridge/HikariCP

## Frontend

13. TailwindCSS - dokumentacja: https://tailwindcss.com/docs
